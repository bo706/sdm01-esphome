# T3.1 无市电读固件版本：请导师判断

T3.1 没有读到版本字符串，已经停了。请判断原因和下一步。

## 已确定的事实

ESP 是通的。ESPHome 2026.10.2，设备 `<电表IP>`，MAC `<电表MAC>`，2.4GHz 信道 11，信号大约 -62 dB 到 -68 dB。用的是官方 `text_sensor` 平台 `modbus_controller`，只读地址 135（固件版本，10 字节）。没有 lambda，没有读序列号。日志 `baud_rate: 0`，串口没有占用 GPIO20、GPIO21。

供电：没有市电。USB-TTL 只用 3.3V 和 GND，经红色转接板进 7 针口。转接板的 TX、RX 没有接到 USB-TTL，IO9 短接帽没有装。

Modbus 按工单：19200、8N1，从机地址 247，寄存器 135，功能码 03。请求发出后大约 2 秒没有应答，日志是 `Stop waiting for response from 247`，以及 `Request not sent: function 0x3 register 135`。没有版本字符串。

目前能确定的是：ESP 在线，组件配置就是上面这些，这一帧没有收到应答，所以没有字符串。

## 做过的尝试

2. 同一状态下对调过一次 TX/RX，仍超时。
3. 引脚改回后，功能码改成 04 试了一次，仍超时。
4. 7 针插紧后，只用原配置又读了一次：TX=GPIO21、RX=GPIO20、功能码 03。固件编译时间 `2026-11-13 10:16:04 +0800`，日志确认是这两个脚。仍然超时。10:33 没有再刷机，又看了一次日志，结果相同。

没有扫波特率，没有扫地址。T3.2 没做。芯片上现在是第 4 次的配置。
